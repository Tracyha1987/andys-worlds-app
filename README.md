# Andy's Worlds — iPhone app

Learning boss-battle game for grades 4–10 (Math, Science, History, Space, California).
Includes a 2-player "Tug of War" mode: siblings or friends race each other on one phone, each at their own grade.
Built with Capacitor 7; cloud build with Codemagic (no Mac needed).

- `www/` — the game (HTML + questions + pictures)
- `assets/` — app icon and splash screen sources
- `docs/` — privacy policy & support page (GitHub Pages)
- `store/` — App Store text and screenshots
- `codemagic.yaml` — cloud build that uploads to TestFlight
- **HUONG_DAN.md** — step-by-step guide (Vietnamese)
